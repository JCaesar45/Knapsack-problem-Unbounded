The Engine

How the algorithm prints money

We convert floating-point constraints into integer capacity via decimal scaling, then run a 2D unbounded dynamic program. Time complexity is O(n · W · V) where W and V are scaled capacities. Space is O(W · V). No fractional items. No gut feelings. Only math.

Scale

Normalize weight and volume to integers by extracting the largest decimal precision across all inputs.

DP Grid

Build a value table indexed by remaining weight and volume capacity.

Reconstruct

Backtrack through optimal states to return the exact item counts.

function knapsackUnbounded(items, maxW, maxV) { const scale = Math.max( ...items.flatMap(i => [i.weight, i.volume].map(d => d.toString().split('.')[1]?.length || 0 ) ), maxW.toString().split('.')[1]?.length || 0, maxV.toString().split('.')[1]?.length || 0 ); const f = 10 ** scale; const W = Math.round(maxW * f); const V = Math.round(maxV * f); const dp = Array.from({length: W+1}, () => new Float64Array(V+1).fill(0)); for (const it of items) { const w = Math.round(it.weight * f); const v = Math.round(it.volume * f); for (let i = w; i <= W; i++) for (let j = v; j <= V; j++) dp[i][j] = Math.max(dp[i][j], dp[i-w][j-v] + it.value); } return dp[W][V]; }
